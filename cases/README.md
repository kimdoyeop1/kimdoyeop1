## 공개 기준

- 넣지 않은 것: 고객사 내부 시설명 · 위치, IP · 포트 등 네트워크 구성, 실제 태그명 · 주소표, 화면 원본, 계정 정보, 단말 고유 정보.
- 숫자는 규모(개수 · 주기 · 용량)와 검증 결과만 적었습니다.
- 제조사 통신 규격은 분석 방법과 구조만 적고 명령 코드는 적지 않았습니다.
